# 표현 조각 보충복습

## 사용자 흐름

- 기초 문장·중급/고급 읽기·업무·여행 수업에서 선택형 보충연습을 연다.
- 표현, 조각별 뜻과 역할, 바꾼 예문, 뜻/빈칸/듣기 선택 문제를 연습한다.
- 오답과 도움받은 답은 본문·문법 복습과 별도인 보충복습에 저장한다. 한번 등록된 문제의 후속 응답도 보존한다.
- `/language/chunk-review`에서 지금 예정된 문제, 저장한 전체 문제, 자유 재연습을 고를 수 있다. 기초·업무·여행·읽기 과정으로 범위를 좁힐 수 있다.
- 저장 목록의 '이 문제 다시 풀기'는 정답과 예문을 미리 열지 않고 그 문제부터 시작한다. 자유 재연습은 표현 설명부터 시작한다.
- 풀이 위치는 저장하지 않는다. 닫은 뒤에는 목록에서 다시 시작한다. 저장된 오답 이력은 정답을 맞혔다고 삭제하지 않는다.

## 저장 안내

- '이 기기에 저장했어요'는 로컬 저장이 확인되었다는 뜻이다. 클라우드 저장 완료 표시가 아니다.
- 다른 기기의 기록은 같은 계정으로 동기화가 정상 완료되면 합쳐진다. 실제 서버 반영 여부는 기존 동기화 상태로 확인해야 한다.
- 저장 중에는 다음 문제·즉시 재연습·재저장 중복 클릭을 막는다. 저장 실패 시 같은 답과 응답 시각, 같은 attempt ID로 재시도한다.
- 저장 중이거나 실패한 상태에서도 닫을 수 있지만, 아직 확인되지 않은 답은 남지 않을 수 있다는 안내를 표시한다. 이전 저장 기록은 지우지 않는다.
- 계정·저장 세대가 바뀌거나 기록을 읽지 못하면 기존 화면의 임시 답은 제거한다. 잘못된 기록을 빈 기록으로 덮어쓰지 않는다.
- Web Locks가 없어도 IndexedDB 공통 저장 순서를 사용할 수 있으면 기존 수업과 보충복습을 연다. IndexedDB까지 사용할 수 없거나 차단·중단되면 일반 학습 화면 대신 소유자가 확인된 기기 기록의 제한된 읽기 전용 요약과 다시 연결하기·홈으로 돌아가기 안내를 제공한다. Web Locks만 되더라도 IDB 실패를 우회하지 않는다. 구버전 탭과 기존 비참여 writer의 한계 및 실제 브라우저 미검증 범위는 [저장소 호환성 검토](japanese-storage-browser-compatibility.md)를 따른다.
- 로그아웃은 인증 종료와 이 기기 기록 정리를 구분한다. 인증 종료 후 일본어 기록 정리에 실패하면 로그아웃 완료와 기록 정리 미완료를 따로 알린다.
- 콘텐츠가 없어졌거나 알 수 없는 문제 ID도 저장 이력은 유지하며, 해당 문제의 연습 버튼만 제공하지 않는다.

## 도움과 소리의 의미

- 표현·뜻·해설을 이미 본 보충연습, 즉시 재연습, 같은 화면에서 정답 해설을 본 뒤의 응답은 도움 포함으로 기록한다.
- 문장 보기 대체는 reading 모드이고 도움 포함이다.
- 소리 버튼을 누른 기록은 audio 모드이지만 실제 청취 확인이나 듣기 능력 인증이 아니다.
- 재생 끝 콜백을 받지 못했거나 실패·중단·다른 음성 선점이 있었으면 도움 없는 청취 응답으로 다루지 않는다. 소리를 전혀 시도하지 않은 듣기 문제의 정답도 독립 청취 성공으로 다루지 않는다.
- 기존 무료 일본어 기기 음성 경로만 사용한다. 타자 입력, 마이크, 녹음, 음성대화, 새 외부 음성 생성은 추가하지 않는다.

## 보존 범위

선택한 학습 단계, 기존 수업 진도, 본문/문법 SRS 점수와 일정은 보충복습에서 변경하지 않는다. 자동 단계 승급이나 취소 기능 복구는 하지 않는다. 저장 데이터와 잠금·초기화·기기 간 병합의 자세한 동작은 별도 저장 계층 검토를 따른다.

## 검증 범위

실제 TSX를 React 정적 렌더링과 합성 hook/event로 실행하고 가상 저장소 모델로 저장 대기·실패·같은 답 재시도·닫기·재진입·소유자 전환·원격 갱신·오디오 실패/중단을 검사한다. 이 검사는 실제 브라우저에서 로그인 후 학습, 새로고침, 두 탭 동시 실행, 작은 화면 배치, 물리 기기 소리, 클라우드 반영을 검증한 것이 아니다. 운영 배포 전 별도 실사용 검증이 필요하다.
