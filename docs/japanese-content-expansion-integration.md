# 일본어 중급·기계개발 읽기 콘텐츠 확장: 연결 전 검토

2026-11-08. 이번 작업은 콘텐츠 모듈과 검사만 준비한다. 새 단원은 앱 화면에 아직 연결하지 않았고 원격 반영·배포도 하지 않았다. 이전 개발본은 비공개 백업의 파일 해시를 검증해 별도로 보존했다.

## 교육과정 역할

- 중급 읽기 8단원은 기존 f13~f20 연결문장 8수업을 대체하지 않고 그 뒤에 이어갈 후보이다. 일정·전언·조건·수동형에서 시작해 가상 개발 문서의 수량·목적·미확정 상태·복수 공지로 확장한다.
- 기계개발 심화 6단원은 기존 고급 응용 6단원의 뒤에 이어갈 후보이다. 도면 개정, 공차 변경 요청, 시험 근거와 한계, 대안 비교, 조건부 의견, 사양 불일치 확인을 읽는 연습이다.
- 범위는 읽기 이해와 표현 비교다. 기술 용어가 많거나 글이 길다는 이유만으로 고급 능력을 인증하지 않는다. 실무 설계·품질·안전 판정, 공식 시험 대비 전체 과정도 아니다.
- 모든 자료는 원작 가상 사례다. 실제 회사 도면·개발자료·사용자 기록을 사용하지 않았다.
- 자기점검은 일본어 예문과 설명을 비교하는 활동이다. 입력창·작문 채점·음성대화·녹음·그림·발음평가를 추가하지 않는다.

## 수준 설계의 참고와 한계

국제교류기금의 읽기 활동 안내는 문형 수보다 실제 목적을 달성하는 읽기를 강조한다. 이를 참고해 각 단원에 목표와 선수학습을 붙였으며, 원문이나 기존 문제를 복사하지 않았다. 해당 기관이 이 콘텐츠를 평가하거나 공인한 것은 아니다.

- [국제교류기금 읽기 활동 안내](https://www.kyozai.jpf.go.jp/kyozai/help/material/comprehension/ja/render.do)
- [JLPT 공식 인정 목표](https://www.jlpt.jp/about/levelsummary.html): 읽기·듣기와 언어 지식의 범위를 구분한다. 앱의 초급·중급·고급을 JLPT나 CEFR 등급과 동일시하지 않는다.
- [MISUMI 치수 공차 용어 설명](https://jp.misumi-ec.com/tech-info/categories/machine_design/md01/c1146.html): 공차가 지정 치수의 허용 범위와 관련된 용어임을 확인하는 참고로 사용했다. 이 자료의 수치·규격을 수업의 설계 권장값으로 옮기지 않았다.
- [OSG 공차와 허용차 설명](https://faq.osg.co.jp/faq/show/7801?category_id=43&site_domain=default): 상·하한의 전체 차이인 공차와 기준 치수에서 한계값까지의 차이인 허용차를 구분하는 근거로 확인했다. ±표기와 전체 폭을 혼용하지 않게 검수했다.

자료 구성은 자체 설계다. 실제 학습자의 정답률·시간·오개념 분석, 일본어 원어민 교육자와 기계개발 실무자의 최종 검토, 실제 기기 듣기 품질은 아직 확인하지 않았다.

## 화면에 연결할 때 보존할 조건

1. `middle-01`~`middle-08`, `upper-mech-01`~`upper-mech-06`의 ID를 유지한다. 기존 f/w/t 및 upper-01~06 ID와 기록을 변경하지 않는다.
2. 새 중급 읽기를 기존 고급 전용 화면에 단순 연결하면 안 된다. 해당 화면은 뒤로가기·목록 링크가 고급으로 고정되어 있으므로 읽기 화면을 일반화하고 실제 단원 수준에 맞는 링크를 검증해야 한다.
3. 현재 선택 단계와 단원 열람을 구분한다. 새 단원 완주·정답률·자료 갯수로 자동 승급하거나 이전 단계를 잠그지 않는다.
4. 복습은 기존 기록 구조를 유지한다. 신규 ID를 문항별 병합·계정 격리·초기화 범위에 연결하고, 기존 문항은 내용 수정으로 정답 의미가 바뀌지 않게 관리한다.
5. 본문 도움·예시 비교와 독립 회상을 구분한다. 같은 날 반복이나 예시 확인만으로 숙달을 인증하지 않는다.
6. 기존 문장 듣기만 재사용한다. 새 유료 TTS 생성·마이크 권한·음성 대화를 추가하지 않는다. 실제 기기 일본어 발음·긴 문단 재생 중지·페이지 이동 시 중지를 별도로 확인한다.
7. 로컬 실제 브라우저에서 작은 화면·이동·새로고침·저장 재조회·오류 재시도·계정 전환을 검증한 뒤에만 검사용 브랜치 반영 여부를 판단한다. 자동 콘텐츠 검사로 이 절차를 대체하지 않는다.

## 여전히 남는 교육과정

중급의 문법 범위, 한자·어휘 누적 복습, 긴 문맥 듣기, 난도가 다른 글을 비교하는 읽기, 고급의 다양한 장르와 논지·뉘앙스 학습은 계속 확장해야 한다. 이 14개 단원 추가만으로 초급부터 고급까지의 전체 교육과정을 완료 처리하지 않는다. 이전부터 취소된 말하기·타자·그림 기능은 남은 작업 목록으로 되살리지 않는다.
