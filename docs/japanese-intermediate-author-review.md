# 중급 읽기 8단원 작성자 검토

작성일: 2026-11-08
대상: `data/japaneseIntermediateLessons.ts`
범위: 최초 작성 시점에는 독립 자료였으며, 현재 로컬 후보의 읽기·조각 연습에 연결된 원작 가상 읽기 콘텐츠. 중급 진입부터 확장까지의 선택 단원이며, 중급 전체 과정 완성이나 JLPT·CEFR 등급을 보장하지 않는다.

## 구성

- `JAPANESE_INTERMEDIATE_LESSONS: JapaneseContentUnit[]`에 middle-01~08 수록.
- 8단원, 일본어 16문단과 한국어 번역 16개, 어휘 40개, 문법·연결어 설명 24개.
- 3지선다 48문항: 본문 이해 32문항, 새 상황 적용 16문항.
- 각 단원에 예시 표현 비교·선택 활동 1개, 일본어 예시, 한국어 해설, 체크리스트 3개.
- 각 단원에 `level`, `domain`, `fictional: true`, `focus`, `prerequisites` 명시.
- 01~04는 일상 안내에서 독해 틀을 익히고 05~08에서 가상 기계개발 문서에 적용한다.

## 순서와 난도 검토

1. middle-01: 이유·결과와 변경·유지 항목 구분. ので, そのため, まま, 정해진 연락 방식 설명.
2. middle-02: 누가 한 말인지와 완료·예정을 구분. 안내 게시, 방법 발표, 접수 시작을 분리.
3. middle-03: 조건, 기한, 신청과 예약 확정 구분. 날짜 계산보다 조건 연결을 중심으로 구성.
4. middle-04: 수동형의 처리 대상·행위자와 전달 주체 구분. 확인 표시의 범위를 제한.
5. middle-05: 가상 부품표의 한 세트당 員数와 두 세트 합계, 비교 기준과 적용 대상을 읽기.
6. middle-06: 가상 시험 기록의 정리 목적과 정리 방법을 구분. 목적과 측정된 결과를 구별.
7. middle-07: 가상 도면의 부품명 표기 수정안을 읽고 改訂欄·承認状況·適用開始日을 구분.
8. middle-08: 앞에서 배운 변경 범위·기한·검토 상태를 두 공지에 함께 적용.

초기 단원에서 수동형 설명보다 먼저 수동형이 불필요하게 등장하지 않도록 02의 안내 게시를 능동형으로, 03의 행사 개최를 쉬운 존재 표현으로 바꿨다. 단원 01에는 ことになりました의 의미를 추가했다. 전체 문장 난도와 어휘량은 실제 초급 학습자 시험으로 확인하지 않았으므로, 이 순서는 교육 효과가 검증된 난도 등급이 아닌 콘텐츠 설계안이다.

## 전달된 검토 의견 반영

- middle-04-q5의 「山田さんに送られました」를 「山田さん宛てに送られました」로 바꿨다. 해설에도 宛て가 수신자를 명시함을 반영했다. 이 첫 수정에서는 문항 ID·선택지·정답을 유지했고, 최종 수신 대상 표현 수정은 아래에 별도로 기록했다.
- 최종 정확성 검토에서 04-q5의 「宛てに送られました」는 수신 대상으로 발송했다는 뜻이며 실제 수령 완료를 보장하지 않음을 반영했다. 질문·선택지의 수령 표현을 수신 대상으로 고치고, 해설에 수령 완료는 확인할 수 없음을 명시했다. 이 추가 수정에서도 문항 ID와 정답 인덱스 1은 유지했다.
- 같은 혼동을 줄이기 위해 04 본문은 「森さんから展示担当の川田さんへ渡されます」로 발신·수신을 명시하고 번역·문법 설명을 맞췄다.
- 05의 일반 라벨 수량 사례를 가상 부품표로 교체했다. 조립체 A/B의 부품 P는 한 세트당 각각 10/12개이며 각 두 세트분의 총수는 20/24개다. 장당/라벨에 관한 이전 표현이 남지 않도록 번역·어휘·문항·해설·비교 활동을 모두 대조했다.
- 07의 일반 제목 축약 사례를 가상 도면 개정란의 부품명 표기 수정안으로 교체했다. 6월 3일 행의 제안 기록, 6월 4일 미승인, 6월 5일 검토 예정, 적용 시작일 미정의 관계를 유지했다.
- 07의 범위는 「カバーＡ」에서 「保護カバーＡ」로 부품명 표기를 바꾸자는 안이다. 부품 자체의 변경, 형상·치수·공차·품질판정·조작 절차는 추가하지 않았다.
- 두 재구성 단원의 ID와 정답 위치는 유지했다.

## 작성자 내용 대조

- 각 정답을 본문 또는 새 상황의 명시적 문장에 대조했다. 오답을 같은 뜻의 다른 표현으로 만들지 않고, 날짜·대상·상태·범위가 다른 진술로 구성했다.
- 01: 토요일에서 일요일로 변경되며 오후 2시·같은 도서실·같은 책·무료 참가비는 유지된다. 참가 불가 연락 기한은 금요일이다.
- 02: 어제 안내 게시, 다음 주 월요일 신청 방법 안내, 다음 달 교실 시작 예정이다. 신청 시작일·참가비는 미제시다.
- 03: 신청서 발송 마감은 5월 10일 오후 5시, 견학은 5월 18일이다. 발송 후 이틀 무응답은 문의 조건이지 마감 연장이 아니다.
- 04: 접수 담당 모리가 수집·전달하고 전시 담당 가와다가 작품명·전시 장소를 확인한다. 글 수정은 각 작가의 역할이다. 파란 표시가 글 수정 완료를 뜻하지 않는다.
- 05: 12−10=2개는 세트당 차이, 24−20=4개는 두 세트 합계 차이다. 새 상황 3×2=6개도 확인했다. 표에 없는 조립체나 실제 제품으로 일반화하지 않는다.
- 06: 목록 작성 목적은 기록 검색 시간 단축이다. 전후 시간을 측정하지 않았으므로 단축된 분량은 알 수 없다. 시험 방법·결과 수정이나 실제 시험 수행을 지시하지 않는다.
- 07: 개정란에 안이 있는 것, 예시가 있는 것, 검토 예정인 것은 사용 승인과 다르다. 검토일과 미정인 적용 시작일을 혼동하지 않는다.
- 08: 7월 10일 오후 2시·제2회의실에서 같은 날 오후 3시·제3회의실로 변경된다. 7월 8일 정오 자료 마감은 유지된다. 안을 읽는 회의이지 채택 결정 회의가 아니다.
- 한국어 번역에서 주체·시제·날짜·수량·가능/예정/미정 표현과 제한 범위를 대조했다.
- 모든 본문은 새로 작성한 가상 사례다. 외부 원문 복사나 실제 회사·사용자 자료는 사용하지 않았다.

## 실행한 검사

1. TypeScript 단독 타입 검사 통과:
   `node node_modules/typescript/bin/tsc --noEmit --allowImportingTsExtensions --target ES2022 --module ESNext --moduleResolution bundler data/japaneseIntermediateLessons.ts`
2. Node 내장 assert를 이용한 파일 직접 import 검사 통과:
   - 단원 수, 순서, ID·문항 ID 중복, 메타데이터, 문단·어휘·문법 설명·문항·체크리스트 수.
   - 일본어 본문 200~350자 범위, 가나 읽기 형식, 한국어 번역 존재.
   - 이해 4개와 적용 2개 구분, 3개 선택지·정답 인덱스·해설 존재.
   - 기존 6개 콘텐츠와 단원 ID·문항 ID·본문 문자열 충돌 없음.
   - 비교·선택 전용 활동, 작문·입력·녹음·음성 기능 지시와 등급 보장 문구 없음.
   - 수신자 명료화와 재구성된 부품표 수량·도면 승인 상태의 핵심 문장 확인.

## 실행하지 않은 범위

- 실제 학습자·일본어 교육 전문가 검증.
- 최종 통합 콘텐츠 테스트와 앱 전체 lint/build/test.
- 브라우저 표시, 선택 동작, 진행 기록·저장·탐색 검증.
- 기존 화면 연결, GitHub 푸시, 운영 배포.
- 실제 기계의 안전·설계·수량 적합성 판정.

현재 결과는 독립 콘텐츠 파일과 작성자 검토 기록이다. 앱 사용 가능 상태나 브라우저 검증 완료로 표현하지 않는다.
