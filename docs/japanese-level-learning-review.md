# 일본어 단계 선택과 반복 학습: 개발 검토

검토일: 2026-11-08. 기준: `jace3695/yeoni-ai` 검사용 브랜치 `agent/fitness-record-priority`, 커밋 `425c1ac75485f5f83ee152e337571f34ca2bfb3a`.

## 현재 상태

단계 선택과 반복 학습의 첫 개발분을 로컬에서 구현했다. 전체 교육과정 완성, 실사용 검증 완료, 원격 반영 또는 배포 완료가 아니다. 실제 브라우저 검증이 막혀 검사용 브랜치 푸시도 보류한다. 운영 배포, 원격 DB migration 적용, 유료 API 호출, 실제 사용자 기록 변경은 하지 않았다.

## 기존 코드에서 확인한 점

- 기존 62수업은 기초 20·업무 22·여행 20의 목적별 경로다. 초급·중급·고급 전체 교육과정이 이미 갖춰진 구조는 아니다.
- 단어 1,111개, 문장 1,186개, 문법 51개와 단계별 한국어 문법 안내가 있으나 자료 개수만으로 특정 수준을 이수했다고 볼 수 없다.
- 기존 학습 ID, 진도, 오답, 저장 단어·문장, 복습 간격 체계는 보존했다.
- 기존 파일명 `curriculumAdvanced`는 허가·규칙 등 기초 확장 내용도 포함한다. 이를 공식 고급 등급으로 인정하거나 완료 표시하지 않는다.
- 앱 음성대화·녹음·발음평가와 타자·그림 연습의 신규 복원은 하지 않는다. 기존 고정 일본어 문장 듣기 기능은 재사용한다.

## 이번 구현

1. `/language/levels`에 초급·중급·고급 화면을 추가했다. 다른 단계 살펴보기와 현재 단계 선택은 구분된다. 명시적인 선택 버튼만 현재 단계를 바꾼다.
2. 초급은 기존 f01~f12를 연결했다. 마지막 초급 수업을 마쳐도 f13으로 자동 이동하지 않고 초급 반복 화면으로 돌아간다. 중급·고급을 보거나 선택해도 이전 기록이 사라지지 않는다.
3. 중급은 기존 f13~f20의 연결문장 8수업을 우선 연결했다. 이는 중급 진입용 첫 범위이며 중급 전체 문법·독해를 갖춘 완성 교재가 아니라는 안내를 표시한다.
4. 고급 영역에는 새로 작성한 읽기·표현 응용 6단원, 선택 문제 36개를 추가했다. 각 단원은 가상 글 2문단, 어휘 5개, 해설, 본문 문제 4개, 새 상황 적용 문제 2개, 예시 표현 비교로 구성된다. 글 전체 길이는 약 212~243자이며 고급 전체 교육과정이나 시험 대비 완성본은 아니다.
5. 새 단원에는 타자 입력창이 없다. 선택 문제와 예시 비교 체크만 기록한다. 자유 글쓰기·자동 작문 채점·마이크 요청·발음평가·음성대화를 추가하지 않았다.
6. 정답·오답·도움 사용과 복습 예정일을 저장한다. 같은 날 반복만으로 간격을 계속 늘리지 않는다. 본문을 다시 읽은 뒤 맞힌 답은 도움 받은 답으로 처리한다. 며칠에 걸친 독립 정답 기록과 단순 단원 연습 완료를 구분하며 자동 승급하지 않는다.

## 기록 보호와 수정 사항

- 계정과 기록 초기화 세대를 저장 전후 확인한다. 손상되거나 새로운 버전의 기록은 덮어쓰지 않고 오류를 표시한다.
- 두 기기의 서로 다른 문항·단원 기록을 병합한다. 같은 문항의 충돌은 가장 최근 관찰 전체를 선택하므로 서로 다른 시도의 필드를 섞어 숙달을 만들어내지 않는다. 모든 시도의 이벤트 원장을 저장하는 방식은 아니다.
- 단계 선택에는 별도 시각이 있어, 다른 기기에서 문제를 풀었다는 이유로 명시적인 단계 선택이 되돌아가지 않는다.
- 같은 탭의 원격 기록 적용 뒤 화면 갱신 이벤트를 발행한다. 기존 기초 수업 진도 변경도 새 단계 화면에 재조회한다.
- 새 기록 키를 기존 초기화 범위에 넣었다. 서버의 기존 초기화 함수도 새 키를 포함해야 하므로 `20261108040658_add_japanese_level_reset_key.sql`을 준비했다. 최신 기존 함수의 키 하나만 추가하고 ACL·SECURITY INVOKER·기존 초기화 동작을 보존한다. **이 파일은 원격 DB에 적용하지 않았다. 배포 전에 별도 검토와 적용이 필요하다.**

### 실제 브라우저 검증: 미완료

로컬 가상 검사 서버와 Playwright 스크립트는 준비했다. Chromium이 실행 환경에서 `socket() failed: Operation not permitted`로 시작하지 못해 테스트 본문은 실행되지 않았다. 허용된 실행 재시도도 같은 제약이었고, 관리 브라우저는 로컬 서버에 `ERR_CONNECTION_REFUSED`를 반환했다. 보안 설정 변경이나 접근 제한 우회는 하지 않았다.

따라서 화면 클릭·이동·뒤로/앞으로·새로고침·저장 후 재조회·저장 오류 재시도·320/390/768px 화면·계정 전환의 **실제 브라우저 성공을 주장할 수 없다**. 실제 로그인, 원격 DB 동기화, 기기 일본어 음성 설치·실제 청취, 물리 휴대폰 동작도 미검증이다. 자동검사와 빌드 통과는 이 검증을 대신하지 않는다.

## 다음 개발·검수 범위

1. Chromium이 실행되는 허용된 개발 환경에서 아래 가상 화면 검사를 완료하고 스크린샷을 직접 검토한다. 배포 없이 로컬에서 할 수 있다.
2. 허가된 시험 계정으로 실제 로그인·클라우드 저장·다른 기기 복원·계정 전환·초기화 후 재유입 방지를 검증한다. 실제 개인 기록은 사용하지 않는다.
3. 중급 문법·긴 글·문맥 듣기, 고급 장문·논지·뉘앙스·상황별 표현을 단계적으로 확대하고 일본어 내용과 문항을 검수한다. 현재 8개 연결수업과 6개 응용단원만으로 전체 과정을 완료 처리하지 않는다.
4. 사용자가 초급을 충분히 반복한 뒤 직접 중급을 선택하는 흐름을 유지한다. 점수로 다음 단계를 강제로 열거나 자동 이동하지 않는다. 이전 단계 복습은 계속 열어 둔다.
5. 실제 브라우저 검증·최신 브랜치 확인·변경 내용 검토·비공개 백업이 끝난 뒤에만 허용된 검사용 브랜치에 반영한다. 운영 병합·배포와 원격 migration 적용은 별도 범위다.

## 로컬 가상 화면 검사 재현

기존 프로젝트 의존성과 `scripts/browser-qa`의 esbuild를 사용한다. 임의의 인증 정보나 `.env`가 필요하지 않다. 서버는 127.0.0.1:8886에만 열린다.

```sh
node scripts/japanese-levels-qa/server.mjs
# 별도 터미널에서:
node --experimental-strip-types scripts/japanese-levels-qa/check.mjs
```

스크립트는 실제 React 컴포넌트와 가상 계정·가상 음성을 이용한다. 외부 요청을 차단하고 실제 마이크 사용을 금지한다. 성공할 경우 임시 검사 폴더에 결과 JSON과 화면 이미지를 생성한다. 현재 결과 JSON과 스크린샷은 생성되지 않았다. 이 스크립트 성공도 실제 로그인·원격 DB·발음 청취 검증 완료를 뜻하지 않는다.
