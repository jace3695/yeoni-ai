# 기계개발 일본어 읽기 6단원 작성 검토

검토일: 2026-11-08
대상: `data/japaneseMechanicalLessons.ts`

## 작성 범위

- 독립 원작 가상 콘텐츠 6단원, 일본어 본문 18문단, 한국어 번역 18문단, 용어 42개, 설명 18개, 객관식 36문항이다.
- 단원마다 본문 이해 4문항과 새로운 문서 상황 적용 2문항을 구분했다. 모든 문항은 3지선다이며 정답 인덱스 0·1·2가 전체에서 각 12개, 단원별로 각 2개다.
- `level: 'advanced'`는 앱 안의 학습 분류다. 고급 과정 전체 완성, 특정 JLPT·CEFR 수준 도달 또는 업무 자격을 보장하지 않는다.
- `writing`은 기존 타입 이름만 유지한다. 예문 비교와 자기점검이며 입력·작문·타자·그림·녹음·발음 평가·음성 대화 활동을 요구하지 않는다.
- 실제 회사 자료, 사용자 자료, 비밀정보를 사용하지 않았다. 문서의 근거·조건·범위·상태를 읽는 교재이며 가공 절차, 운전 설정, 안전성 판정이나 승인 우회 방법을 제시하지 않는다.
- 화면, 학습 저장, 기존 콘텐츠 및 승인 절차 구현을 변경하지 않았다. 앱 화면 연결·푸시·배포를 수행하지 않았다.

## 단원별 검토

글자 수는 일본어 본문 3문단의 Unicode 코드 포인트를 합한 값이다. 문장부호·숫자·로마자를 포함하며 문단 사이 줄바꿈과 번역은 제외했다.

## 검수와 자동 확인

- 모든 단원에서 일본어 3문단 합계 400~650자, 용어 7개와 가나 읽기, 설명 3개, 문항 6개, 자기점검 3개를 확인했다.
- ID는 `upper-mech-01`~`upper-mech-06`, 문항은 해당 단원 ID 뒤 `-q1`~`-q6`이다. 문항 ID 36개가 고유하며 정답 범위·선택지 중복·새 상황 표시 위치를 검사했다.
- 일본어와 한국어의 조건·부정·시제·주체·숫자 범위를 문단별로 대조했다. 확인된 사실과 요청·예정·조건부 의견을 분리했다.
- 36문항 모두 본문 또는 문제에 새로 제시한 문장 안에 정답 근거를 두었다. 오답은 그 근거와 충돌하거나 확정되지 않은 범위를 확정하는 내용으로 구성하고, 정답 위치를 재대조했다.
- 공차와 허용 편차, 공급처를 뜻하는 供給元, 발언자를 나타내는 意見を述べた人 등의 기술·문서 표현을 자체 교정했다. 첫 단원 예문 비교의 A/아래 예시 지시를 명확히 했다.
- Node의 TypeScript 직접 로딩 및 구조 assertion: 통과.
- `tsc --noEmit --strict --target es2020 --module esnext --moduleResolution bundler --allowImportingTsExtensions --skipLibCheck data/japaneseMechanicalLessons.ts`: 통과.
- 전 앱 회귀 검사나 브라우저 검증을 통과했다는 의미는 아니다. 이 보고서의 자동 확인은 독립 콘텐츠 구조와 해당 파일의 타입 검사 범위다.

## 남은 검증

- 일본인 기계개발 현업 전문가와 한국어 교육·번역 전문가의 독립 검수는 받지 않았다. 작성자의 언어·내용 점검은 전문가 검수를 대체하지 않는다.
- 실제 학습자의 난이도, 반복 학습 효과, 오답 해석, 학습 시간과 접근성은 검증하지 않았다.
- 앱 화면의 줄바꿈·긴 지문 표시·정답 해설 노출·선택 흐름·저장·복원 동작과 모바일·브라우저 동작은 이 콘텐츠 파일로 확인하지 않았다.
- 실제 회사의 도면 관리, 승인 권한, 견적 조건이나 품질 판단에 적용할 자료가 아니다. 업무상 판단에는 해당 조직의 공식 문서와 담당자의 검토가 필요하다.
