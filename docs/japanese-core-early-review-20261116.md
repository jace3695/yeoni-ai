# 본수업 조기 반복과 예정 복습 보호

## 범위와 판단

기준 검사 브랜치 `715eefd29c4ade80a9594efe63d6fff486d74d60` 및 r11의 본수업 완료 계산을 가상 자료로 검토했다. f01을 같은 날 5분 간격으로 새 세션에서 다섯 번 완료하면 복습 간격이 1→3→7→14→30일로 늘고 세 번째부터 ‘안정 3/측정 3’이 된다. 첫 복습일이 오기 전에 다음 날 복습이 한 달 뒤로 밀리는 것은 재현 사실이다. 실제 사용자 기록을 조사한 결과는 아니다.

운영 `9b06701d4d590a093b6a36dcc1a11b445b74f5b2`의 해당 계산 함수는 V2 문항 계획 인자 차이를 제외하면 같다. 전체 모듈이나 전체 운영 기능이 r11과 같다는 뜻은 아니다.

본수업의 기존 문서는 ‘해본 수업’을 숙달과 구분하고 재도전 정답을 다음 날 복습으로 남긴다. 상위·청크 학습은 이미 예정 전 반복을 새 간격 학습 성공으로 세지 않는다. 그러나 본수업에 동일한 조기 반복 규칙을 명시한 기존 제품 사양은 확인하지 못했다. 따라서 이번 변경은 확인된 일정 지연을 막기 위해 그 보호 원칙을 본수업에도 적용하는 **정책 확장**이며, 기존 명시 사양 위반의 수정이라고 단정하지 않는다. 학습 효과나 실사용 정확도를 입증한 것은 아니다.

## 새 완료에만 적용하는 최소 변경

- 이미 알려진 미래 복습 예정일이 있고, 현재 답이 정답이며 첫 오답·도움 사용 증거가 없으면 기존 간격, 예정일 원문과 간격 학습 성공 연속을 보존한다.
- 실제 새 관찰, 관찰 횟수, 세션 ID는 계속 기록한다. 느린 정답도 일정은 뒤로 밀지 않는다.
- 관찰이 없는 옛 초안도 미래 일정은 늘리지 않는다. 이를 독립 정답의 증거로 간주하거나 없는 관찰·성공 수치를 생성하지 않는다.
- 예정 시각과 같거나 지난 답은 기존 간격·속도·입력 방식 규칙을 따른다. 날짜 누락·잘못된 옛 날짜는 이번 변경에서 추정 복구하지 않고 기존 명시 답변 시 계산을 유지한다.
- 현재 오답, 첫 오답 후 교정, 도움 사용은 기존 즉시/다음 날 단축 규칙을 유지한다.
- 저장 재시도 중복 방어, V2/옛 문항 ID, 미출제 항목, 다른 수업과 추가 필드는 보존한다.
- 과거 학습 내역을 읽을 때 재계산하거나 기존 ‘안정’ 기록을 일괄 수정하지 않는다. 저장 키·동기화·인증·권한·음성·AI 호출은 바꾸지 않는다.

## 검증과 남은 범위

- 수정 전 새 경계 회귀 중 7개 실패를 보존했다. 수정 후 3개 관련 파일 46/46 통과.
- 독립 전후 432조합 비교: 조기 보호 36, 기존 동작 유지 396, 예상 밖 차이 0. 검토자는 두 시험 파일 42/42를 별도로 확인했다. 이 수치는 합산된 서로 다른 사용자 사례가 아니다.
- 기존 의미 선택/직접 입력 속도 차이 시험은 예정 시각을 실제 도달한 fixture로 명시했으며 임계값·단언은 약화하지 않았다.
- 전체 회귀·타입·빌드의 최종 결과는 후보 검증 보고서에 별도로 기록한다.
- 실제 브라우저의 완료→재학습→새로고침→저장 재조회, 실제 계정·기기간 동기화, 모바일은 미검증이다. 이전 접근 거부를 새 URL/포트/도구로 우회하지 않는다. 가상 함수 검증을 실제 UI나 운영 검증으로 부르지 않는다.
- 운영 배포·운영 DB 적용·실사용자 자료 조회·유료 전송은 하지 않았다. r11과 롤백 후보는 그대로 둔다.
