# 일본어 학습 콘텐츠 후속 품질 검토

검토일: 2026-11-09 KST. 최신 통합 후보의 내용을 바탕으로 한 로컬 개발 결과다. 운영 반영, 실제 계정·회사자료·유료 서비스·원격 AI 호출은 포함하지 않는다.

## 개선 내용

- 기존 고급 일반 읽기 upper-01~06에 학습 목적·읽기 준비·핵심 표현 두 개·근거 찾기 안내를 보완했다. 다른 14단원과 같은 기존 화면 경로에서 사용된다. 새로운 수업을 6개 만든 것이 아니다.
- 같은 6단원에 원작 표현 비교 6개와 본문 근거 24개를 추가했다. 비교 예문은 원문의 사실을 바꾼 설명이 아니라 별도 가상 상황이다. 본문 밖 새 상황 문제에는 원문 근거를 잘못 붙이지 않는다. 정답 근거는 응답 후에만, 표현 비교는 해당 수업 문제를 마친 뒤 선택적으로 표시한다.
- middle-06은 날짜별 기록을 찾는 목적어를 자연스럽게 고쳤다. 본문·번역·조각·변형·듣기 텍스트·관련 근거를 함께 맞췄다. 기록 검색 시간이 실제로 줄었다는 결과는 추가하지 않았다.
- middle-07은 이미 접수한 상태와 앞으로 검토할 일정을 「すでに案を受け付けており、六月五日に検討する予定です」로 분리했다. 정확한 접수 날짜는 단정하지 않는다. 「ている」가 언제나 완료라는 일반화도 하지 않는다.
- upper-mech-02-q5의 「火曜までに」를 ‘화요일까지 확인 예정일을 회신’으로 고쳤다. 확인이나 변경 자체의 완료 기한이라는 뜻은 아니다.
- upper-mech-03 예시에 제작일이 서로 다르다는 조건을 명시했다. upper-mech-06의 비교 안내에서는 원문의 확인과 새 예문의 자료 제출을 구별했다.
- upper-04-q3 근거는 도입 후 숙련 직원이 많이 근무했다는 사실만 언급한다. 전후 직원 구성비가 달라졌다는 미제시 사실을 덧붙이지 않는다.
- 공용 한국어 뜻 설명 두 곳의 조사 연결을 고쳐 기존 62수업 496문항 중 210개 해설만 바꿨다. ‘사진’라는 같은 오류 대신 ‘…의 뜻은 …입니다.’를 쓴다.

## 보존한 계약

- 읽기 20단원·120문항, 조각 연습 82단원·246문항의 ID와 정답 인덱스는 같다.
- 중급 읽기 48문항의 모든 필드는 그대로다. 기계개발 읽기는 위 1문항의 정답 선택지 문구와 해설만 수정했으며 정답 위치는 같다.
- 기존 62수업·496퀴즈는 해설 외 생성 데이터 전체가 같다. 문항 위치 기반 기록 키도 바꾸지 않는다.
- 읽기 조각은 middle-06/07의 문구만 수정했다. middle-06 듣기의 정답 문구가 명료해졌지만 의미와 정답 위치 1은 같다.
- 진도, 오답·도움 기록, 복습 간격, 세대·저장 키·동기화, 단계 선택, AI 입력 코드에는 손대지 않았다. 기존 답과 폐기된 단원 답을 삭제하거나 자동으로 단계 이동시키지 않는다.
- 타자 입력, 녹음, 발음 평가, 앱 음성 대화, 그림 연습을 복구하지 않았다. 고정된 듣기용 일본어 텍스트와 선택형 문제를 유지했다.

## 자료 확인 범위

이 단계의 표현 비교와 예문은 원작 가상 자료다. 실제 회사 문서나 외부 강의의 문구를 가져오지 않았다. 사용자 요청에서 확인한 짧은 표현→조각과 조사→단어·시제 변형→듣기·선택 문제→오답 복습 흐름과 기존 화면을 대조했다. 이번 수정만으로 특정 앱을 직접 사용하거나 유료 강좌·유튜브 영상을 끝까지 시청했다고 주장하지 않는다. 기존 출처별 확인 범위를 넓혀 주장하지 않는다.

문법 설명의 좁은 확인에는 다음 공식 공개 텍스트를 참고했다. 이 기관이 이번 예문을 검수한 것은 아니다.

## 검증과 한계

새 회귀 검사는 기존 내용의 해시·ID·정답 위치, 완료/예정/기한의 명시 조건, 근거 인용과 원문 대응, 기록 보존과 수동 단계 선택을 검사한다. 기존 실제 React 컴포넌트의 가상 렌더·상태 검사는 모든 20단원의 근거 노출 시점과 선택적 비교 경로를 포함한다. 전체 검사·타입·lint·빌드의 최종 결과와 파일 해시는 별도 동결 보고서에 기록한다.

이 검토는 독립적인 모델 기반 언어·의미 대조이며 원어민 교사 검수, 실제 학습자 효과 시험, JLPT/CEFR 인증이나 중·고급 전체 과정 완성 판정은 아니다. 가상 React 렌더는 실제 브라우저 터치·글자 배치·음성 출력·다중 탭 저장을 대신하지 않는다. 실제 브라우저, 실제 음성 재생, 로그인·클라우드 동기화와 구버전 서버 데이터 보호는 이 콘텐츠 수정으로 해결하거나 검증했다고 하지 않는다.
